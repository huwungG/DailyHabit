## What is this?
A single-page habit tracker called **Habit Snowball**. It gamifies habit-building using a "snowball / automaticity" metaphor: every check-in pushes a habit toward the **Vô thức (Unconscious / Autopilot)** stage, and lapses decay the score back. You can also track bad habits (where check-ins *lower* the score).

Everything runs in the browser. There's no server except a tiny Google Apps Script endpoint that mirrors state to a Google Sheet so you can use the same data on phone and computer.

## Stack
- **Frontend**: plain `index.html` + `styles.css` + vanilla JS in `app.js`. No framework, no build step.
- **Backend**: `Code.gs` (Google Apps Script) deployed as a Web App.
- **Database**: one Google Sheet, one tab named `habit_snowball`, one row: `[key='state', stateJSON, updatedAt]`.
- **Auth**: shared passcode stored in Apps Script Properties (`SYNC_PASSCODE`), sent as `?p=...`.

## Data model
```js
// localStorage key: 'habit_snowball_v1'
{
  habits: [
    {
      id: 'h_abc123...',          // generated by makeId()
      name: 'Đọc sách 30 phút',
      emoji: '📚',
      type: 'good',               // 'good' = check-ins raise score; 'bad' = lower it
      score: 65,                  // 0–100, automaticity score
      streak: 12,                 // current consecutive-day streak
      lastCompleted: 1725000000000,
      lastDecayAppliedDate: '2026-9-5',  // YYYY-M-D, no zero-padding
      history: [
        { timestamp: 1725000000000, hourOfDay: 7, dateKey: '2026-9-5' }
        // multi check-ins per day are allowed
      ]
    }
  ]
}
```

## Core concepts
- **Score (0–100)** = how "automatic" the habit has become. Visualized via 3 stages:
  - **Khởi động** (Launch) — low score
  - **Tích tụ** (Accumulate) — middle
  - **Vô thức** (Unconscious / Autopilot) — high
- **Streak** = consecutive days with at least one check-in.
- **Decay** — if you miss days, score drops. Tracked via `lastDecayAppliedDate`.
- **Bad habits** — same UI, but check-ins *reduce* score instead of raising it.

## Sync flow
1. User opens sync modal, pastes Web App URL + passcode, hits **💾 Lưu cấu hình**.
2. Auto-sync kicks in: every state change triggers a debounced (~5s) sync.
3. Each sync = pull from Sheets → merge with local → push merged result back.
4. Merge rule: same `id` → keep the one with the newer last `history[].timestamp`. Unique IDs are unioned. No data is ever deleted by merge alone.
5. Manual buttons:
   - **⬆ Đẩy lên cloud** — force push (with conflict warning if server is newer).
   - **⬇ Tải về từ cloud** — overwrite local (destructive, requires confirmation).

## How to run it
### Local-only (no sync)
Just open `index.html` in a browser. Everything works from `localStorage`.

### With sync
Follow `SYNC_SETUP.md`. Short version:
1. Create a Google Sheet.
2. script.google.com → New project → paste `Code.gs` → enable Sheets API service.
3. In editor run `setPasscode("your-passcode")` once.
4. Deploy as Web App (Execute as: Me, Access: Anyone).
5. Copy Web App URL → paste into the app's sync modal along with the passcode.

To use on phone: host `index.html` / `app.js` / `styles.css` on any static host (GitHub Pages, Netlify, etc.), open the URL, configure sync the same way.

## Things to remember
- All UI strings are in **Vietnamese** — don't translate.
- `dayKey()` produces un-padded dates (`2026-9-5`, not `2026-09-05`). Keep it consistent.
- `normalizeHabit()` is the safety net for any habit coming from storage or sync — add new fields there.
- Bump `styles.css?v=N` in `index.html` whenever CSS changes so the browser cache refreshes.
- Sheet schema is intentionally tiny (1 row × 3 cells). Don't "improve" it into a relational layout without a reason.
- `localStorage` is always the local source of truth; Sheet is a mirror, not the master.

## Quick-edit checklist
- Touched state shape? → update `normalizeHabit` + `DEFAULT_STATE` (and `Code.gs` if sync-relevant).
- Touched sync flow? → update `SYNC_SETUP.md` too.
- Touched CSS visually? → bump `?v=N` in `index.html`.
- New habit field? → make sure it has a safe default in `normalizeHabit`.
